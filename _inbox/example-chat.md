# Пример переписки для пайплайна статей

Разговор ниже — учебный. Реальные экспорты кладите рядом и не коммитьте JSON.

## DeepSeek

Скорее всего одновременно работают две схемы GitHub Pages.

User-site `username.github.io` собирается Jekyll с ветки `main`. Когда в корень кладут пустой файл `.nojekyll`, Jekyll **выключается**. Тогда Pages просто раздаёт файлы как есть. Главная ищет `index.html`. Если есть только `index.md` и `_posts/`, корень будет 404. А `/ClubOfSisters/` живёт, потому что там настоящий `index.html` и JSON/Yarn не нужно прогонять через Liquid.

`.nojekyll` как раз и добавляли, чтобы Yarn/OGG/JSON клуба сестёр не пережёвывались Jekyll и не отваливались 404 на каталоге.

## DeepSeek

Ключ API и история веб-чата — разные вещи. `api.deepseek.com` не отдаёт список ваших диалогов с сайта. Экспортируйте чат в JSON или markdown, положите в `_inbox/`, вызовите `tools/deepseek_to_post.py`. Модель сжимает переписку в эссе в голосе блога, скрипт пишет `_posts/YYYY-MM-DD-slug.md` и пересобирает статику. Ключ держите в `.env`, не в git и не в папке ClubOfSisters на Pages.
