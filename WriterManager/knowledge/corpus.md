## W-05 Пайплайн «чат → статья»

1. Экспорт DeepSeek (JSON/MD) или заметка → `_inbox/` (секреты и сырой JSON не в git).

3. LLM: DeepSeek API **или** GigaChat (ключ как в ClubOfSisters Story Keeper) — только `.env`.
4. Файл в `_posts/` + HTML.

API DeepSeek не читает историю web-чата. История = экспорт.
